# 🩺 MediCita

**Bitácora de proyecto — Grupo 2**

Reagendamiento asistido de horas médicas para personas mayores en CESFAM Dr. Alfonso Leng (Providencia).

---

## 📌 El problema

El **CESFAM Dr. Alfonso Leng**, en la comuna de **Providencia**, enfrenta una **saturación** importante de su capacidad de atención. Una de sus causas es la **pérdida de horas agendadas**, particularmente entre **personas mayores**.

Esta pérdida de horas **no responde a irresponsabilidad o desinterés**: responde a barreras reales que enfrenta este grupo etario:

- 🚶 **Dificultades de movilidad** para trasladarse hasta el centro de salud.
- 💻 **Brecha digital**: dificultad para usar plataformas, apps o sistemas de reagendamiento en línea.
- 📵 Falta de recordatorios o canales de aviso adecuados a sus capacidades y hábitos.

El resultado es un círculo vicioso: horas perdidas → menor disponibilidad para otros pacientes → mayor saturación del centro → peor acceso a salud para toda la comunidad, y en particular para quienes más lo necesitan.

## 🎯 Objetivo

Diseñar y validar una solución (proceso, servicio y/o herramienta digital) que **facilite el reagendamiento de horas médicas para personas mayores**, reduciendo la tasa de inasistencia y, con ello, la saturación del CESFAM Dr. Alfonso Leng — sin exigirles competencias digitales que no tienen ni obligarlos a trasladados innecesarios.
